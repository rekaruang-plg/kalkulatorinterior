# Kalkulator Interior Mobile V5.9

Revisi harga rata-rata per m²:
- Total jual rata-rata per m² = total jual proyek / luas aktual.
- Modal rata-rata per m² = total modal proyek / luas aktual.
- Laba rata-rata per m² = laba kotor proyek / luas aktual.
- Ditampilkan pada total Dinding Interior dan PVC.
- Copy customer menampilkan harga rata-rata terpasang per m², tanpa menampilkan modal.
- Copy internal menampilkan harga jual/m², modal/m², dan laba/m².
- Total jual/modal tetap memasukkan tambahan proyek bila ada; pembaginya selalu luas aktual proyek.

Fitur V5.8 (List T Wallboard) tetap dipertahankan.
Upload `index.html` ke Vercel seperti versi sebelumnya.
