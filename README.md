# Kalkulator Interior Mobile V5.8

Revisi List T Wallboard:
- Setiap area yang memakai Wallboard memiliki checkbox **Pakai List T Wallboard**.
- Default tidak dicentang.
- Jika dicentang: jumlah List T = jumlah Wallboard + 1 per bidang fisik. Jika `Jumlah area > 1`, tambahan `+1` diterapkan ke masing-masing bidang.
- Harga jual default List T: Rp85.000/batang.
- Harga modal default List T: Rp75.000/batang.
- List T masuk ke kebutuhan bahan, harga jual, modal, laba, rincian area, dan copy customer/internal.
- Harga jual/modal tetap bisa diubah dari menu Pengaturan.

Upload `index.html` ke Vercel seperti versi sebelumnya.
