# Kalkulator Interior Mobile V5.7

Revisi logika aksesoris pemasangan WPC:

- **Pakai hollow**: kebutuhan `Sekrup hitam 1”` dan `Paku beton 2”` aktif; `Fisher/Baut` tidak dihitung.
- **Tanpa hollow**: `Sekrup hitam 1”` dan `Paku beton 2”` tidak dihitung; `Fisher/Baut` aktif.
- Fisher/Baut default **25 pcs per kantong**.
- Kebutuhan Fisher/Baut mengikuti jumlah clip untuk area WPC tanpa hollow, ditambah buffer default **5%**, lalu dibulatkan ke atas per kantong 25 pcs.
- Jumlah isi kantong dan buffer dapat diubah dari menu Pengaturan.
- Kolom tambahan Fisher/Baut hanya berlaku jika proyek memiliki WPC tanpa hollow.

Contoh: bila clip area tanpa hollow = 200 pcs, target fisher = 210 pcs (buffer 5%), sehingga pembelian = 9 kantong × 25 pcs = 225 pcs.
